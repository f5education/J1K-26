Scenario 1: F5 AI Guardrails (Allowed Sports Turn)

1 Browser POST /api/proxy (Host/Origin: localhost, Content-Type: text/plain, payload: { input: "Recommend soccer ball" })
2 FastAPI checks Host & Origin, reads bounded body (<64 KiB), rotates 192-bit opaque token
3 Server calls POST https://us2.calypsoai.app/openai/shopai-cai-project/chat/completions (Bearer token)
4 F5 scanner passes prompt -> LLM returns choices[0].message.content (HTTP 200)
5 FastAPI appends turn to server history (max 40) -> returns HTTP 200 { response, conversationId }
